# BUBBLE — build rules

The authoritative spec is `../bubble-design-requirements.md`. Section references
below (§n) point at it. Read your step's sections before writing code.

## Non-negotiable

1. **`Math.random()` is banned everywhere** (§25.1). ESLint enforces it; do not
   disable the rule. Anything that looks random — popup position, hit counters,
   which junk arrives — is authored in `/src/script` or derived from the current
   month index.
2. **The sim is pure and React-free.** `/src/sim` imports no React, no DOM, no
   `Date`. `tick(state, month) -> state`. It is the part that gets unit tested.
3. **No component knows which era it is in** (§25.1). Every colour, radius, font,
   metric and duration is a CSS custom property on `:root[data-era="a"|"b"]`.
   The Jan 2002 switch must be one attribute change.
4. **No hex colours outside `src/chrome/tokens.css`.**
5. **Stay inside your step's file list** (§26.2 rule 4). If a step seems to need a
   file outside it, say so rather than widening the change silently.
6. **After Step 9, `npm run verify` must stay green** (§26.2 rule 8).
7. **Never hand-edit `src/data/series.json`** — it is generated by
   `scripts/build-series.ts` (§26.2 rule 7).
8. **Fully offline.** No CDN, no font fetch, no analytics, no network at runtime.
9. **§5.1 content law:** real indices, fictional firms. No real company is ever
   depicted as a scam or a bad investment. Fictional names must not be
   near-misses for real 1996–2006 firms.

## The one number the design rests on

A player who accepts nothing and stays 100% cash goes bankrupt in **March 2000**
(§6, §8.4). `npm run verify` asserts it. If it slips, the game ships broken.

## Layout (§25.1)

```
src/data      generated historical series (JSON). Loaded once at boot.
src/sim       pure functions. tick, run, basket, bands. Unit tested.
src/script    THE RUN — §14.2 as a typed array of 42 dated events.
src/content   message bodies, fact sheets, offer copy, death-card lines.
src/chrome    the browser shell — window, menus, toolbar, address bar,
              status bar, dialogs, popups. Era-themed via CSS custom props.
src/pages     the websites rendered into the chrome's content area.
src/ui        glue. Owns no game logic.
src/dev       presenter tools, behind ?dev=1.
```

## Shared contracts — import, don't redefine

- `src/sim/month.ts` — the clock. Month 0 = Jan 1996, month 131 = Dec 2006.
- `src/sim/ids.ts` — `VehicleId`. Owned by the content agent.
- `src/sim/types.ts` — everything else: `GameState`, `VehicleDef`, `FactSheet`,
  `ScriptEvent`, `Decision`, `RunResult`, `Band`.

## Commands

```
npm run check       lint + typecheck + test — must be green before you finish
npm run verify      the calibration gate (§25.3)
npm run dev         vite dev server
npm run build:series regenerate src/data/series.json
```

## Style

Match the surrounding code. Comments explain *why* and cite the spec section;
they do not narrate what the line does. Motion snaps — no easing anywhere (§23).
